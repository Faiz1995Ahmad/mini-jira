# 🗂️ Mini-Jira

Mini-Jira is a lightweight project management and issue tracking system inspired by Jira. It is built to help teams efficiently manage projects, track tasks, and collaborate — without the complexity of enterprise-grade tools.

---

## 🚀 Features

### 🔐 Role-Based Access Control (RBAC)
- Fine-grained permissions for different user roles
- Roles such as:
  - **Admin** – Full access to system settings and users
  - **Manager** – Manage projects and assign tasks
  - **Contributor** – Work on assigned tasks
- Secure access to resources based on roles

### 📁 Project Management
- Create and manage multiple projects
- Organize tasks within projects
- Track project progress easily

### 📝 Issue Tracking
- Create, update, and delete issues
- Support for:
  - Bug reports
  - Feature requests
  - Tasks
- Set priorities and statuses (To Do, In Progress, Done)

### 👥 Team Collaboration
- Assign tasks to team members
- Monitor progress in real-time
- Improve team productivity and transparency

### ⚡ Lightweight & Scalable
- Minimal and clean UI
- Designed for small to medium teams
- Easy to extend and customize

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/mini-jira.git

# Navigate into the project
cd mini-jira

# Install dependencies
npm install

# Start the development server
npm run dev
```
